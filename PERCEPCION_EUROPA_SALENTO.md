### 1. **Percepción de Seguridad: El Factor Determinante**

#### Pre-Terremoto: Percepción Relativamente Positiva
```
Salento = "Colombia segura", "Destino especial", "Experiencia única"
```

#### Post-Terremoto: Percepción Deteriorada
```
Salento = "Zona de desastre", "Peligroso", "No recomendado"
```

#### Cómo se forma esta percepción:
- **Noticias internacionales:** "Terremoto en Colombia destruye destino turístico"
- **Blogs de viaje:** "Salento ya no es seguro después del terremoto"
- **Foros especializados:** "Evitar Salento por ahora, hay destinos más seguros"
- **Redes sociales:** Videos virales de daños (reutilizados o descontextualizados)

---

### 2. **Búsqueda de Información: El Proceso Europeo**

#### Fase 1: Awareness (Conocimiento del Destino)
```
Usuario europeo busca: "Colombia travel destinations"
→ Resultados: Cartagena, Medellín, Salento (si aparece)
→ Percepción: "Salento parece interesante pero..."
```

#### Fase 2: Research (Investigación Detallada)
```
Usuario busca: "Salento Colombia safety"
→ Resultados actuales: Noticias de terremoto, videos alarmistas
→ Percepción: "Parece peligroso, quizás buscar otro destino"
```

#### Fase 3: Validation (Validación de Seguridad)
```
Usuario busca: "Salento earthquake update", "Is Salento open"
→ Resultados actuales: Información desactualizada, contradictoria
→ Percepción: "No hay información clara, mejor no arriesgarse"
```

#### Fase 4: Decision (Toma de Decisión)
```
Resultado: "Cancelación o elección de otro destino"
→ Impacto económico: Pérdida de turista europeo (gasto promedio €800-€1,200)
```

## 🚨 BARRERAS ESPECÍFICAS DEL MERCADO EUROPEO

### 1. **Distancia Geográfica y Psicológica**
- **Problema:** Europa está lejos, no tienen contexto local
- **Solución:** Contenido que "acerca" la experiencia, testimonios de europeos que visitaron

### 2. **Percepción de Colombia en General**
- **Problema:** Colombia asociada con peligros históricos
- **Solución:** Enfatizar que Salento es una excepción segura, destacar éxito de turismo en Colombia

### 3. **Dependencia de "Autoridades Oficiales"**
- **Problema:** Europeos confían en gobiernos, no en fuentes locales
- **Solución:** Integración con autoridades oficiales, citación de ministerios, embajadas

### 4. **Seasonality y Planificación**
- **Problema:** Europeos planifican con mucha antelación
- **Solución:** Información de largo plazo, previsiones de estabilidad, planificación de 6-12 meses

### 5. **Language Barriers**
- **Problema:** Preferencia por contenido en idioma nativo
- **Solución:** Multi-idioma completo, contenido localizado culturalmente
