## Elementos Gráficos

### Fondos
- **Gradientes:** Verde oscuro a verde claro (135°)
- **Texturas:** Patrones sutiles de puntos o líneas
- **Overlay:** Oscurecer para legibilidad de texto

### Bordes y Esquinas
- **Border radius:** 8-16px para tarjetas
- **Botones:** 50px (completo redondeado)
- **Badges:** 30px (redondeado)

### Sombras
- **Sombra suave:** 0 4px 6px rgba(0,0,0,0.1)
- **Sombra media:** 0 10px 20px rgba(0,0,0,0.15)
- **Sombra fuerte:** 0 20px 40px rgba(0,0,0,0.2)

## Uso de Plantillas

### Para generar imágenes:
1. Abrir plantilla HTML en navegador
2. Capturar pantalla o usar herramienta de screenshot
3. Recortar al tamaño deseado
4. Comprimir para web (WebP recomendado)

### Para videos:
1. Seguir script de secuencias
2. Usar colores de marca en textos
3. Aplicar transiciones suaves
4. Incluir subtítulos
5. Agregar música colombiana alegre
