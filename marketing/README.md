# Marketing - Salento a la Mano

## Campaña de Marketing Digital

Assets de marketing para la campaña de lanzamiento de **Salento a la Mano**.

## Estructura

- `plantillas/` - Templates HTML/CSS para piezas gráficas
- `videos/` - Scripts para videos (Reels, TikTok)
- `svg/` - Iconos y logos SVG
- `GUIA_MARCA_VISUAL.md` - Guía de identidad visual

## Piezas Disponibles

### Plantillas Redes (1080x1080)
- Post lanzamiento
- Post defensivo
- Post aliados

### Stories (1080x1920)
- Story Don Chucho
- WhatsApp status

### Cover (1640x856)
- Facebook cover

### Videos
- Reel lanzamiento (45s)
- Reel defensivo (30s)
- TikTok Don Chucho (20s)

## Uso

Abrir plantillas HTML en navegador y capturar pantalla.
